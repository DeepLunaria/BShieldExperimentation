# NoMount Bypass for BShield

This module is a workaround used for NoMount bypass for BShield.

## Notes

- You must have NoMount latest version intergrated in the kernel ([7046c7a](https://github.com/maxsteeel/nomount/tree/7046c7ad3ee0bf4ae66e80f6b93b1e30db0cb4e3) and upper)
- If you see your BShield protected app not working, please check [docs/DETECTION.md](../docs/DETECTION.md)
- It maybe cause some problem in some app, you you see so, please unmount your app you want to using
